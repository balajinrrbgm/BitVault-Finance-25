# BitVault Finance Frontend

React/Next.js frontend for BitVault Finance DeFi platform.

## Features

- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Wallet Integration**: Starknet wallet connectivity (ArgentX, Braavos)
- **Real-time Data**: Live vault statistics and yield information
- **Modern UI**: Clean, professional interface optimized for DeFi

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

## Built With

- Next.js 14
- React 18
- Starknet React
- Tailwind CSS
- TypeScript
